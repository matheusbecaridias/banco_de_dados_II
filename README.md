# banco_de_dados_II
Banco de Dados II 🗄️

Este repositório armazena projetos, scripts e estudos avançados desenvolvidos na disciplina de Banco de Dados II do curso técnico em Desenvolvimento de Sistemas (Subsequente), fundamentado na Nova Matriz Curricular 2025.
📖 Sobre a Disciplina
A unidade curricular de Banco de Dados II aprofunda os conceitos de persistência de dados e integra a modelagem de dados à Programação Orientada a Objetos (POO). O foco está na criação de aplicações robustas que se conectam a bancos de dados e na implementação de lógicas de servidor eficientes.

    Carga Horária: 134 horas-relógio (160 horas-aula).
    Semestre: 2º Semestre.

🛠️ Tecnologias e Conhecimentos
De acordo com o plano de curso, os estudos nesta disciplina abrangem:

    Programação Orientada a Objetos (Java): Classes, objetos, atributos, métodos, encapsulamento, herança, polimorfismo e classes abstratas.
    JavaScript: Desenvolvimento e integração de scripts.
    Conexão com Banco de Dados: Implementação de persistência de dados em aplicações.
    Ambiente Script Server-side: Manipulação de request e response, comunicação assíncrona de threads e criação de módulos.
    Integração via APIs: Desenvolvimento de APIs para comunicação com o front-end.
    Segurança e Acessibilidade: Implementação de práticas seguras no tratamento de dados.

🎯 Habilidades Desenvolvidas
Ao longo deste repositório, são aplicadas as seguintes habilidades previstas:

    Codificação de rotinas utilizando linguagens específicas (Java/JavaScript).
    Implementação de frameworks e ferramentas de colaboração em equipe.
    Realização de testes funcionais em programas de computador e aplicativos.
    Apoio técnico na elaboração de documentação de sistemas e registros para refinamento de resultados.
